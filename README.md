# 守护光源 · 深海

一个装进 **DSH（DeepSeek Harness）侧栏**的原创小游戏。

你操控一条**鲸鱼少女**在无限下潜的深海里游动，朝鼠标方向自动吐光弹。
**光就是命** —— 光耗尽了就结束。咬光点、打怪都能回光。

> 操作：鼠标移动决定朝向 · `WASD` 游动 · `空格` 加速下潜 · `Q` 释放鲸落 · `Esc` 退出

---

## 怎么装

DSH 的「添加插件」接受：**包名（可带版本）/ Git 地址 / tarball / 本地绝对路径**。

这个包没有发布到 npm，所以用 **tarball 或本地路径**：

### 方式一：tarball（推荐发给别人）

```bash
dsh plugin add ./dsh-deep-sea-1.0.0.tgz
```

### 方式二：本地目录

```bash
dsh plugin add C:/Plugins/dsh-deep-sea
```

装完**从托盘完全退出 DSH 再重新启动**，侧栏就会出现「守护光源 · 深海」。

## 玩法

### 光就是命

- 顶部光条持续下降，**降到 0 就结束**
- 咬**光点**回光；**击杀怪物**也会掉光点
- 升级可以加光上限、降光耗

### 升级

每攒满一管经验就**三选一**（鼠标点击，或键盘 `1` `2` `3`）：

| 升级 | 效果 |
| --- | --- |
| 锐光 | 光弹伤害 +18% |
| 疾吐 | 射速 +14% |
| 光海 | 光上限 +20% |
| 固光 | 光消耗 −12% |
| 聚光 | 光点回光 +20% |
| 牵引 | 磁吸范围 +30% |
| 分光 | 同时发出多发光弹（散射） |
| 游速 | 游动速度 +10% |
| 残影 | 受击无敌时间 +0.3 秒 |

**等级上限**随「历史最深」成长：初始 2 级，之后**每 1500m +2**。
想变强就得潜得更深 —— 顶到上限时经验条会变金色，提示「潜更深才能升级」。

### 深海生物

**越大的鱼血越厚**（每级 ≥1.5 倍），前六种各有自己的机制：

| 鱼 | 机制 |
| --- | --- |
| 小刺球 | 靠近就点火，**0.32 秒后爆炸**（可打爆或游开）；死亡时爆炸波及同伴 |
| 水母 | **减速光环**（范围内游速砍半，有可见的青色圆环） |
| 吸光虫 | 碰到额外**吸血** |
| 暗影鳗 | 唯一会**突进**的鱼；受伤会逃跑 |
| 提灯鱼 | 死亡时**闪光致盲** |
| 铁甲蟹 | 正面减伤 + **撞击顶飞** + 概率带盾 |
| 深渊猎手 | 死亡留下**遮挡视野的墨云** + 概率带盾 |
| 深渊巨口 | **弹幕** + 概率带盾 |
| 铁壁鲸鲛 | **减伤 62%**（只吃 50% 伤害）+ 连续受击伤害递减 |
| 暗影鳗·猎杀体 | **伪装成普通暗影鳗**：外观速度完全一样，带 1~3 层格挡盾 + 受击闪避加速 |

> 猎杀体平时**完全看不出**，只有打上去才会亮起紫光、露出盾 —— 你自己小心。

### 品质

品质按**深度门槛**解锁，每档强度是上一档的 **×1.60**：

| 品质 | 门槛 | 强度 |
| --- | --- | --- |
| 凡品 | 0m | ×1.15 |
| 精良 | 0m | ×1.84 |
| 稀有 | **3500m** | ×2.94 |
| 史诗 | **7000m** | ×4.72 |
| 传说 | **10500m** | ×7.55 |
| 神话 | **14000m** | ×12.08 |

前 3500m 只有凡品和精良 —— 先熟悉世界。

### 蓝色大肥鱼

会偶尔游过的吉祥物。**出现频率固定**，但每次随机带不同的东西，看它**头顶**就知道：

| 头顶 | 是什么 | 效果 |
| --- | --- | --- |
| 空着 | 发光大肥鱼 | 沿途掉光点（71%） |
| **小鲸鱼** | 鲸落 | 经过**屏幕中场**时掉下来，10 秒内捡（10%） |
| **小饭碗** | 米饭 | 同上（19%） |

带道具的**不提供光源**，它是来送礼的。

- **鲸落**：拾取后存进背包（HUD 显示 `鲸落 xN [Q]`，可存多个）。
  按 **Q** 释放 —— 屏幕中央闪出「鲸落！」，一条**纯蓝色线框巨鲸**从天而降，
  **清空全屏**，落地弹一下再消失。
- **米饭**：拾取后立刻召唤助战 **「萌萌的大肥鱼」**，
  **继承你 100% 当前属性**，自己找目标、自己吐弹，**存在 10 秒**。
  最后 5 秒开始**渐变透明度闪烁，频率越来越快**。

### 空格加速下潜

按 `空格` **加速的是深度计数**（"潜到多少米"涨得更快），**不改变鱼本身的机动**。
消耗**耐力条**（光条右边的「耐」），空了必须等回复才能再冲。

## 特性

- **零音频文件** —— 所有音效和背景音乐都是 **Web Audio 现场合成**（不涉及任何第三方素材版权）
- 画面素材只有一张玩家立绘，其余全部是代码绘制
- 单文件客户端，无外部依赖
